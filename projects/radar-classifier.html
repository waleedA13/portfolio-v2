Berkeley Lab ML research internship, summer 2023

Precipitation classifier on a Raspberry Pi

We turned raw mmWave radar files into precipitation labels on a Raspberry Pi, so a remote sensor could classify weather without a bigger computer. It was my first research project. I was still at City College of San Francisco.

Result
The pipeline classified a reading in under a second on the Pi.
Role
Machine learning research intern
Where
Lawrence Berkeley National Laboratory, Jun to Aug 2023
Stack
Python, NumPy, Pandas, Linux, Raspberry Pi, Bitbucket
Links
Full report

The goal

Weather and snowpack sensing in remote places needs hardware that runs on little power with nobody around to watch it. The project used a small mmWave radar, which writes raw binary files.

From binaries to data

The radar's files aren't readable on their own. The pipeline decoded each file's header using JSON configuration files that describe the format, then wrote clean, structured CSVs. To make sure the decoding was right, we checked the output against Infineon's own radar visualizations.

The models

We trained SVM and K-means models to classify snowpack and precipitation. We picked them because they're small enough to run on a Pi.

Code and report

The code lived in the lab's private Bitbucket, so the report is the public record. It has the setup, data, and results in more detail.
