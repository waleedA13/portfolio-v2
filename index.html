  1. Aug 2026 – now

    Undergraduate Researcher UC San Diego

    A Mixture-of-Experts model sends each token to a few "experts," and you don't know which ones until the router picks them. If those weights aren't loaded yet, the GPU stalls. We're testing whether we can predict those choices early enough to prefetch the weights. We have the experiment pipeline running on Mixtral 8x7B, and getting there meant loading the model and checking that its architecture and tokenizer match what we expect.

    Python · PyTorch · Mixtral
